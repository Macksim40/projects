# Банк‑ассистент: модуль обработки банковских данных

## Цель проекта

Модуль для обработки и форматирования данных о банковских операциях: маскировки конфиденциальной информации, фильтрации и сортировки транзакций, преобразования форматов дат.

## Функциональность

* **Маскировка номеров карт и счетов** с сохранением конфиденциальности данных.
* **Фильтрация транзакций** по статусу (`EXECUTED`, `CANCELED` и др.).
* **Сортировка транзакций** по дате (по возрастанию/убыванию).
* **Преобразование формата даты** из ISO 8601 в формат ДД.ММ.ГГГГ.

## Установка

1. Создайте новый проект в PyCharm.
2. Скопируйте код модуля в файл `bank_assistant.py` в корне проекта.
3. Убедитесь, что Python 3.6+ установлен в окружении PyCharm.

## Использование

### Импорт функций

```python
from bank_assistant import (
    mask_account_card,
    get_date,
    filter_by_state,
    sort_by_date
)
Доступные функции
1. mask_account_card(input_string: str) -> str
Маскирует номер карты или счёта в строке.

Параметры:

input_string — строка с типом и номером (например, 'Visa Platinum 7000792289606361').

Возвращает: строку с замаскированным номером.

Примеры:

python
mask_account_card("Visa Platinum 7000792289606361")
# → "Visa Platinum 7000 79** **** 6361"

mask_account_card("Счёт 73654108430135874305")
# → "Счёт **4305"

mask_account_card("Maestro 1596837868705199")
# → "Maestro 1596 83** **** 5199"
2. get_date(date_string: str) -> str | None
Преобразует дату из формата ISO в формат ДД.ММ.ГГГГ.

Параметры:

date_string — дата в формате ISO (с микросекундами или без).

Возвращает: дату в формате «ДД.ММ.ГГГГ» или None при ошибке.

Примеры:

python
get_date("2024-03-11T02:26:18.671407")
# → "11.03.2024"

get_date("2023-12-25T15:30:45")
# → "25.12.2023"
3. filter_by_state(transactions: list, state: str = 'EXECUTED') -> list
Фильтрует транзакции по статусу.

Параметры:

transactions — список словарей с транзакциями.

state — статус для фильтрации (по умолчанию 'EXECUTED').

Возвращает: отфильтрованный список транзакций.

Пример:

python
filtered = filter_by_state(test_data, 'CANCELED')
# Возвращает только транзакции со статусом 'CANCELED'
4. sort_by_date(transactions: list, reverse: bool = True) -> list
Сортирует транзакции по дате.

Параметры:

transactions — список словарей с транзакциями.

reverse — порядок сортировки (True — по убыванию, False — по возрастанию).

Возвращает: отсортированный список транзакций.

Пример:

python
sorted_newest = sort_by_date(test_data, reverse=True)
# Транзакции от самых новых к старым

sorted_oldest = sort_by_date(test_data, reverse=False)
# Транзакции от самых старых к новым
Полный пример работы
python
# Тестовые данные
test_data = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
]

# 1. Маскировка данных
print("Маскированная карта:", mask_account_card("Visa Gold 5999414228426353"))
# → "Visa Gold 5999 41** **** 6353"


# 2. Преобразование даты
print("Дата:", get_date("2024-03-11T02:26:18.671407"))
# → "11.03.2024"

# 3. Фильтрация по статусу
executed = filter_by_state(test_data)
print("Выполненные транзакции:")
for t in executed:
    print(f"ID: {t['id']}, Дата: {get_date(t['date'])}")

# Вывод:
# ID: 41428829, Дата: 03.07.2019
# ID: 939719570, Дата: 30.06.2018


# 4. Сортировка по дате (новые сначала)
sorted_transactions = sort_by_date(test_data, reverse=True)
print("Транзакции по убыванию даты:")
for t in sorted_transactions:
    print(f"ID: {t['id']}, Статус: {t['state']}, Дата: {get_date(t['date'])}")
Обработка ошибок
Некорректный номер карты/счёта в mask_account_card() — возвращает исходную строку с предупреждением.

Неверный формат даты в get_date() — возвращает None и выводит сообщение об ошибке.

Отсутствие ключа 'date' или 'state' в словарях — может вызвать ошибку в sort_by_date и filter_by_state. Убедитесь, что все словари содержат необходимые ключи.
