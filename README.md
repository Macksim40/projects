# Банк‑ассистент: модуль обработки банковских данных

Модуль предоставляет функции для фильтрации, сортировки и преобразования банковских транзакций, а также маскировки конфиденциальных данных (номеров карт/счетов).

## Цель проекта

Создать удобный и безопасный модуль для предварительной обработки банковских операций:
- фильтрация по статусу транзакции;
- сортировка по дате;
- преобразование формата даты;
- маскировка номеров карт и счетов.

## Функциональность

- `filter_by_state(transactions, state="EXECUTED")` — фильтрация транзакций по статусу.
- `sort_by_date(transactions, reverse=True)` — сортировка транзакций по дате (ISO 8601).
- `get_date(date_string)` — конвертация даты из ISO в формат `ДД.ММ.ГГГГ`.
- `mask_account_card(input_string)` — маскировка 16‑значного номера карты.

## Установка

1. Убедитесь, что у вас установлен Python версии 3.8 или выше.
2. Создайте папку проекта и поместите файл `bank_assistant.py` внутрь.
3. Дополнительные зависимости не требуются — используются только стандартные библиотеки.
